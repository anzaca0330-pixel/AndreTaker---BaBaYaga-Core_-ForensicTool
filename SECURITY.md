# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AndreTaker — BabaYaga Core, please report it privately by:

- Opening a private vulnerability report (if enabled)
- Or contacting the lead investigator directly via encrypted email: `andretaker@proton.me`
- Or contacting the repository owner directly via GitHub

We take all security issues seriously and will respond as quickly as possible.

## Supported Versions

We actively support the latest stable release and recommend all users to update regularly.

## Disclosure Policy

We follow responsible disclosure practices. Please allow us 48 hours to respond before disclosing the vulnerability publicly.

## 🛡️ Enterprise Trade Secret & Data Privacy Mandate (Secreto de Empresa)

All proprietary algorithms, local AI model architectures (`AndreTaker`), custom forensic scripts, metadata indices, and security mitigation mechanisms contained within this repository and evidence vault are strictly protected under **Trade Secret Law & Enterprise Data Privacy Standards**.

### Core Operational Privacy & Defensive Controls:
1. **Air-Gapped Local Inferences:** All LLM model inferences (`Ollama: AndreTaker`), document scans, and SHA-256 hash verifications execute 100% locally on isolated hardware.
2. **Enterprise Data Privacy Clause (Zero Cloud Mining):** No evidence files, internal logs, or proprietary prompts may be transmitted to external servers, trained on public AI models, or mined for telemetry.
3. **Active Anti-Surveillance & Hardware Defense:** Persistent port lockdown, sysfs USB/SATA power cut shields, and Anti-Palantir metadata mutation protocols (`AntiPalantir`) are continuously active to counter zero-day threats and physical/network intrusion attempts.
